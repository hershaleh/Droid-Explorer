# Droid Explorer

אפליקציית Android לניהול קבצים, אחסון ומדיה, בהשראת Windows 11.

> הפרויקט בהקמה. אין עדיין יכולות לשימוש.

## מבנה

| מודול | תפקיד |
| --- | --- |
| `:app` | האפליקציה: נקודת כניסה והרכבת הרכיבים |
| `:core:capabilities` | מודל היכולות: מה כל ספק/מנוע תומך בו בפועל, מצב Root, ומצב בשלות של יכולת |
| `:ui:design` | מערכת העיצוב בהשראת Windows 11 (ערכות נושא, RTL) |

מודולים נוספים (אחסון, מנועים, רכיבי תוכן, Root) יתווספו לפי תוכנית העבודה.

## בנייה

הבנייה והבדיקות רצות ב-CI של GitHub (`.github/workflows/ci.yml`).
קובץ ה-APK לבדיקה מצורף ל-Artifacts של כל הרצה.

בנייה מקומית (דורשת Android SDK ו-JDK 17):

```
gradle assembleDebug testDebugUnitTest
```

## כללי עבודה

- אין להכניס למאגר סיסמאות, מפתחות API, מפתחות חתימה או קובצי keystore. סריקת סודות רצה על כל push.
- `main` מכיל רק קוד שעבר CI. העבודה נעשית בענפים נפרדים.
- החלטות ארכיטקטורה מתועדות ב-`docs/decisions/`.
- יכולת נחשבת "נתמכת", "ממומשת" או "נבדקת" רק עם ראיות. ראו `docs/capability-matrix.md`.
