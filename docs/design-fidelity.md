# נאמנות לעיצוב Windows 11

היעד: דמיון מרבי ל-Windows 11, בכל הרכיבים והחוויה. לא רק "השראה".
המסמך מתעד מה כבר זהה, מה עדיין שונה ולמה, ואיך בודקים.

## כללי עבודה

- כל רכיב נבנה לפי מבנה ומידות WinUI 3 (גובה, ריפוד, רדיוס פינות, מצבי hover/pressed/focus/disabled), לא לפי Material.
- שמות הטוקנים בקוד (`FluentColors`) תואמים לשמות המשאבים ב-WinUI (למשל `ControlFillColorDefault`).
- אין העתקת נכסים קנייניים: לא Segoe UI, לא Segoe Fluent Icons, לא קוד ולא תמונות של Microsoft.
- כל רכיב חדש נכנס לגלריה (`GalleryScreen`) ומצולם אוטומטית ב-CI בבהיר/כהה וב-RTL/LTR.
- הערכים הוכנסו לפי הידע על הטוקנים הציבוריים ועדיין לא הושוו מול מכשיר Windows 11 אמיתי. השוואה כזו היא משימה פתוחה.

## מה כבר ממומש (שלב 1א)

| רכיב | מה זהה ל-Windows 11 |
| --- | --- |
| צבעים | ערכות בהיר וכהה, שכבות, כרטיסים, בקרים, טקסט, הדגשה, סטטוס מערכת |
| טיפוגרפיה | סולם הגדלים והמשקלים של Windows 11 (Caption עד Display) |
| כפתורים | סגנונות Standard, Accent ו-Subtle, גובה 32, פינות 4, מסגרת עם מעבר צבע מלמעלה למטה, מצבי hover/pressed/disabled/focus |
| תיבת טקסט | גובה 32, קו תחתון חזק שהופך לקו הדגשה בעובי 2 בפוקוס |
| מתג וחלונית סימון | מתג 40x20 עם ידית 12, תיבת סימון 20 עם פינות 4 |
| פס התקדמות וטבעת התקדמות | קו רקע דק ופס הדגשה, טבעת 32 |
| ניווט | פריט בגובה 40 עם פס הדגשה 3x16 בקצה ההתחלה (מתהפך ב-RTL) |
| כרטיס הגדרות | מבנה אפליקציית ההגדרות: אייקון, כותרת, תיאור ובקרה בסוף השורה |
| סרגל מידע | ארבע דרגות חומרה עם רקע מותאם |
| חלון דו-שיח | פינות 8, אזור תוכן בהיר ואזור כפתורים כהה, שני כפתורים ברוחב שווה |

## פערים ידועים

| פער | סיבה | תוכנית |
| --- | --- | --- |
| גופן Roboto במקום Segoe UI | Segoe UI אינו בר הפצה. אין גישת רשת בסביבת הפיתוח להורדת גופן חלופי | הוספת Selawik (SIL OFL, תואם מטריקות ל-Segoe UI) אחרי אימות כיסוי עברית. הנקודה היחידה להחלפה: `FluentFontFamily` |
| אייקוני Material במקום Segoe Fluent Icons | אין רישיון לאייקוני Segoe. Fluent System Icons (MIT) לא הובאו עדיין | ייבוא ערכת Fluent System Icons כ-vector drawables, אחרי אימות רישיון |
| אין Mica ואין Acrylic | Android אינו מספק אותם | רקע מלא בצבע בסיס Mica, ותצוגת שקיפות מעודנת. בחינת טשטוש ב-Android 12 ומעלה לפלייאאוטים |
| אין צל וסימון הדגשה בחלונות קופצים | טרם נבנו תפריטי הקשר ופלייאאוטים | שלב 1ב |
| גובה בקרים 32dp | ב-Windows זה הגובה הרגיל. ב-Android אזור המגע המינימלי הוא 48dp, ו-Compose מרחיב אותו אוטומטית | אפשרות "צפיפות" בהגדרות: רגילה (נוחה למגע) וקומפקטית (כמו Windows) |
| חסרים רכיבים | תפריט הקשר, פלייאאוטים, לשוניות, סרגל פקודות, שורת כתובת, טולטיפ, התראות | שלבים 1ב והלאה |
| אנימציות | רק מעברים פשוטים | הוספת עקומות התזוזה של Windows 11 |
