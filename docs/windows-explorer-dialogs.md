# חלונות ותיבות דו-שיח בסייר הקבצים של Windows 11, ומה נעשה בכל אחד

המסמך נכתב מתוך הכרות עם Windows 11 (לא מצילום של מכשיר אמיתי). לפני שמכריזים על דמיון מלא יש להשוות מול מחשב Windows 11.
סימונים: ✅ ממומש, 🔜 מתוכנן, ⛔ לא אפשרי או לא רלוונטי ב-Android.
כלל סגנון: חלונות של מנהל הקבצים בסגנון חלונות הסייר (Win32: שורת כותרת עם X, גוף לבן, פס כפתורים אפור). רק הגדרות וחלונות מיוחדים (למשל שגיאת נתיב) בסגנון הגדרות Windows 11.

## 1. חלונות פעולה על קבצים
| חלון ב-Windows | מה יש בו | אצלנו |
| --- | --- | --- |
| התקדמות העתקה/העברה/מחיקה | אחוזים בכותרת, "פרטים נוספים": שם, זמן שנותר, פריטים שנותרו, מהירות, גרף מהירות, השהיה, ביטול | ✅ אחוזים, שם, פריטים, מהירות, ביטול. 🔜 השהיה וגרף מהירות |
| החלפה או דילוג על קבצים | החלף / דלג / השווה מידע בין שני הקבצים, "בצע זאת לכל הפריטים הנוכחיים" | ✅ |
| השוואת שני הקבצים | שני קבצים עם תיבת סימון: שניהם = שמירת שניהם עם מספר בשם, אחד = החלפה או דילוג | ✅ |
| אישור מחיקה | "האם למחוק?" עם שם ופרטי הפריט, כן/לא | ✅ (אין סל מיחזור ב-Android, לכן מחיקה סופית) |
| שגיאת פעולה | "הקובץ בשימוש", "אין הרשאה", "הנתיב לא נמצא", נסה שוב/דלג/בטל | ✅ הודעת שגיאה. 🔜 נסה שוב/דלג |
| שם ארוך מדי / שם לא חוקי | הודעה שהשם מכיל תווים אסורים | ✅ (בודק תווים אסורים) |
| שינוי סיומת | "אם תשנה סיומת הקובץ עלול להפוך לבלתי שמיש" | 🔜 |
| פעולה דורשת הרשאת מנהל | חלון UAC | ⛔ ב-Android: הרשאת גישה לכל הקבצים (מומש), Root אופציונלי בהמשך |

## 2. תפריטי הקשר
| תפריט | אצלנו |
| --- | --- |
| מקש ימני על שטח ריק (תצוגה, מיין לפי, קבץ לפי, רענן, הדבק, בטל, פתח במסוף, חדש, מאפיינים) | ✅ לחיצה ארוכה על שטח ריק: תצוגה, מיין, קבץ, רענן, הדבק, בחר הכול, פתח במסוף (אם Termux מותקן), חדש, מאפיינים. 🔜 בטל (Undo). ⛔ התאמה אישית של תיקייה, תן גישה ל- |
| מקש ימני על פריט (פתח, פתח באמצעות, העתק כנתיב, שיתוף, גזור, העתק, מחק, שנה שם, מאפיינים) | ✅ לחיצה ארוכה שנייה על פריט נבחר. ⛔ שלח אל, צור קיצור דרך (אין קיצורי דרך בקבצי Android), הוסף למועדפים (🔜) |
| שלוש הנקודות בסרגל הפקודות (בטל, צרוב, דחוס ל-ZIP, מועדפים, העתק נתיב, בחר הכול/אל תבחר/הפוך בחירה, מאפיינים, אפשרויות) | ✅ מה שרלוונטי. 🔜 דחיסה ל-ZIP (שלב ארכיונים), מועדפים, אפשרויות. ⛔ צרוב לדיסק |
| תפריט לשונית, תפריט נתיב (העתק כתובת, ערוך) | 🔜 |

## 3. חלון המאפיינים (Properties)
| לשונית ב-Windows | אצלנו |

| פרטים (למאפייני מדיה: מידות תמונה, אורך, קצב סיביות...) | ✅ פרטים בסיסיים ומידות תמונה. 🔜 מדיה מלאה |
| אבטחה (הרשאות משתמשים) | ✅ הרשאות Unix בלשונית פרטים. ⛔ ACL |
| שיתוף | ⛔ |
| גרסאות קודמות | ⛔ |
| התאמה אישית (סוג תיקייה, סמל) | 🔜 אולי |
| כמה פריטים נבחרים: סך הכול, מכיל | ✅ |

3. אפשרויות תיקייה והגדרות בסגנון Windows 11.
