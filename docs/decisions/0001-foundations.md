# 0001 – החלטות יסוד

סטטוס: מאושר (2026-11-25)

## החלטות מוצר (אושרו על ידי בעל המוצר)

- **הפצה:** בשלב הראשון הפצה עצמאית (APK) לבדיקות. Google Play אולי בהמשך.
- **רישיון:** קוד סגור. נמנעים מספריות AGPL. ספריות LGPL רק לאחר בדיקה וקישור דינמי.
- **Shizuku:** נתמך כאפשרות למשתמשים ללא Root, עם הבהרה ברורה למשתמש. מימוש בשלב הרלוונטי.
- **ענן:** מתחילים ב-SMB, SFTP ו-WebDAV. אחריהם Google Drive.
- **מאגר:** ציבורי זמנית לצורך כלי בנייה חינמיים. ההחלטה אם להפוך לפרטי תתקבל בסיום.

## החלטות טכניות

- Kotlin, Jetpack Compose, Gradle עם Version Catalog.
- minSdk 26, targetSdk 35.
- מודולים נפרדים בקוד, אפליקציה אחת.
- מנוע ויכולות: כל ספק ומנוע מצהיר על `Capability`, והממשק מציג רק פעולות נתמכות.
- רכיבים מסוכנים או כבדים (פענוח ארכיונים, ספריות native, שירות Root) ירוצו בתהליך נפרד.
- בנייה ובדיקה רק ב-CI של GitHub (אין Android SDK בסביבת הפיתוח של Claude).
- ענף `ci-logs` נוצר אוטומטית בכשל בנייה, לצורך אבחון. יוסר כשהתשתית תתייצב.

## נושאים פתוחים

- אופן העדכון המודולרי בהפצה עצמאית: כרגע עדכון של כל ה-APK. מודולים דינמיים אפשריים רק דרך Google Play.
- בחירת גופן עברי ברישיון פתוח.
- אימות רישיון Fluent System Icons לפני שימוש.
